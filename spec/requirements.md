# Requirements — Trend Gacha

> SDD Phase: **Requirements**  
> Status: **Approved**

---

## 1. Problem Statement

ビジネスデザイナー・戦略プランナーがワークショップやブレストを行う際、「未来のトレンド」を起点としたアイデア発想が求められる場面が多い。しかし、トレンド資料は長大なレポート形式であることが多く、ランダムに「1つ選ぶ」体験が欠けている。

**Trend Gacha** は、ガチャ（カプセルトイ）のメカニクスを用いて、未来の兆しをランダムに引けるWebアプリである。

## 2. Target Users

- ビジネスデザイナー
- 戦略プランナー
- ワークショップファシリテーター
- 新規事業開発チーム

## 3. Use Cases

| UC | Actor | Flow |
|----|-------|------|
| UC-1 | ファシリテーター | カテゴリを選択 → DRAW → 結果をチームに共有 → 議論のきっかけにする |
| UC-2 | 個人 | ALL で何度もドロー → 気になるトレンドをメモ |
| UC-3 | データ管理者 | trends.json を編集 → push → ワークショップ前に最新トレンドを反映 |

## 4. Functional Requirements

### FR-1: カテゴリフィルター
- 4段階のフィルター: ALL / MEGA / MIDDLE / MICRO
- ALL は全カテゴリから抽選
- フィルター切替は即座に反映

### FR-2: ガチャドロー
- ユーザーが「DRAW TREND」ボタンをクリック（または Space/Enter）でドロー実行
- ドロー中は2秒程度のスピン演出
- フィルター条件に合致するトレンドからランダムに1件選出
- 直前と同じ結果は回避（候補が2件以上の場合）
- ドロー中は再ドロー不可（二重実行防止）

### FR-3: 結果表示
- ドロー完了後、結果カードがスライドアップで表示される
- カード内容: カテゴリバッジ、タイムフレーム、アイコン（絵文字）、日本語タイトル、英語タイトル、説明文
- 閉じる操作: ×ボタン / 背景クリック / Escapeキー

### FR-4: 履歴
- ドロー結果は履歴リストに追加される（新しい順）
- 履歴アイテムをクリックすると結果カードを再表示
- CLEAR ボタンで全履歴をクリア
- 履歴はセッション内のみ保持（ページリロードでリセット）

### FR-5: トレンドデータ管理
- トレンドデータは `public/data/trends.json` に外部ファイルとして配置
- JSON編集 + git push のみでデータ更新可能（コード変更不要）
- fetch失敗時はフォールバックデータで動作

### FR-6: キーボード操作
- Space / Enter: ドロー実行
- Escape: 結果カードを閉じる

## 5. Non-Functional Requirements

### NFR-1: ホスティング
- GitHub Pages（静的サイト）でホスト
- GitHub Actions による自動デプロイ（push to main）

### NFR-2: パフォーマンス
- FCP < 1.5s
- バンドルサイズ < 100KB gzipped

### NFR-3: レスポンシブ
- モバイル（375px）〜 デスクトップ（1024px+）対応
- モバイルファースト設計

### NFR-4: ブラウザサポート
- Chrome, Safari, Firefox, Edge の最新版

### NFR-5: アクセシビリティ
- キーボード操作対応
- ARIA属性の適切な使用
- カラーコントラスト WCAG AA以上

## 6. Out of Scope（v1.0）

- ユーザー認証
- データベース / バックエンド
- 履歴の永続化（localStorage）
- シェア機能（Web Share API）
- サウンドエフェクト
- PWA対応
- 多言語対応（UI英語版）
- トレンドデータのAI自動生成

## 7. Data Requirements

### トレンドアイテムの必須フィールド

| フィールド | 型 | 例 | 説明 |
|-----------|----|----|------|
| id | string | "mega-001" | 一意識別子 |
| category | enum | "MEGA" | MEGA / MIDDLE / MICRO |
| timeframe | string | "10—20 YEARS" | 時間軸ラベル |
| icon | string | "🧬" | 絵文字1文字 |
| titleJa | string | "ポストヒューマン労働市場" | 日本語タイトル |
| titleEn | string | "Post-Human Labor Market" | 英語タイトル |
| descriptionJa | string | "AI・ロボットが..." | 日本語説明文 |

### カテゴリと時間軸の対応

| カテゴリ | 時間軸 | 意味 |
|---------|-------|------|
| MEGA | 10—20 YEARS | 巨視的・構造変化レベルのトレンド |
| MIDDLE | 5—10 YEARS | 産業・社会レベルのトレンド |
| MICRO | 1—5 YEARS | 身近・実装段階のトレンド |

### 初期データ件数
- 各カテゴリ最低4件、合計12件以上
